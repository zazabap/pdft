Example gallery
===============

Short, runnable scripts that train bases on small random targets. Each one
finishes in a few seconds on a CPU; the plots below are produced by running
them while the docs build.

Run any of them locally from the repository root, e.g.
``python examples/basis_demo.py``. They need the ``plot`` extra
(``pip install "pdft[plot]"``) and write their figures to ``out/``.
