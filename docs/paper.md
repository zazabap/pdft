# Papers

`pdft` is the reference implementation of two papers.

> Shiwen An, Zhongyi Ni, Huanhai Zhou, Jin-Guo Liu.
> **Fast Trainable Multilinear Bases for Image Compression.**
> arXiv:2608.00053 (2026).
> [arxiv.org/abs/2608.00053](https://arxiv.org/abs/2608.00053)

The bases ({class}`~pdft.bases.QFTBasis` and its relatives), the sparsity
losses, the Riemannian optimizers and the compression task
({func}`~pdft.tasks.compress`, {func}`~pdft.tasks.recover`). Demonstrated by
{ref}`sphx_glr_auto_examples_basis_demo.py`, whose page carries the BibTeX
entry.

> Shiwen An, Konstantinos Slavakis.
> **Quantum-Inspired Trainable and Parameter-Efficient Tensor Networks for Image Inpainting.**
> arXiv:2609.17298 (2026).
> [arxiv.org/abs/2609.17298](https://arxiv.org/abs/2609.17298)

The completion solver ({func}`~pdft.tasks.complete`), training a circuit
through it ({func}`~pdft.training.train_basis_steps` on the phase views), and
the argument that the circuit's structure keeps its coherence with the pixels
at the minimum. Demonstrated by
{ref}`sphx_glr_auto_examples_completion_demo.py`, whose page carries the
BibTeX entry. With the package, the paper's Table 1 on DIV2K reproduces to
0.01 dB: 20.72 dB for the DFT, 22.63 dB for the phase-only circuit and
22.75 dB for the four-phase circuit, against 20.72, 22.62 and 22.74 in the
paper.

## Relation to ParametricDFT.jl

`pdft` ports [ParametricDFT.jl](https://github.com/nzy1997/ParametricDFT.jl)
and is pinned to upstream commit {{ upstream_commit_link }}
(`pdft.__upstream_ref__`).
Matching Julia's behavior is the package's main correctness criterion: the
test suite compares Python output against goldens generated by the Julia
reference. Completion is not in the Julia package; its golden is a run of the
inpainting paper's own code (`reference/completion/`). The Python port is
MIT-licensed, as is ParametricDFT.jl (© 2025 nzy1997).
